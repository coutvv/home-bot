# Home Bot

Home telegram bot for loading free content via magnet link

For starting you need next environment variables: 
```shell
# Token to access telegram bot
TELEGRAM_TOKEN=
# Optional params for login to QBittorrent Web UI
QBIT_URL=
QBIT_PASSWORD=
QBIT_USERNAME=
```
